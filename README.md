# Digit
Librairie qui gère des traitements sur les digits.

# Comment l'utiliser ?
Utiliser la classe :
```java
import com.phenix.digit.Digit;
```

Exemple :
```java
import com.phenix.digit.Digit;

void main(String[] args) {
    // Retourne un String sur 2 digits :
    byte b = 6;
    String nombre = Digit.getDigit(b);
    // ...
}
```
